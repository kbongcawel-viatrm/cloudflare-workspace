# Cline project rules

Follow `AGENTS.md` and `.agents/rules/working-agreement.md` as the canonical working agreement.

Before changes:
- Read relevant `.agents/memory/` files.
- Search `.agents/skills/` for matching skills and read each relevant `SKILL.md`.
- Inspect Git state and project conventions.
- Keep credentials and local session state outside Git.

Do not deploy, change DNS, create/delete resources, change permissions, or push to a remote without explicit operator approval.
