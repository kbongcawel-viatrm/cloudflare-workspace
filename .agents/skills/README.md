# Shared agent skills

Skills are stored as directories containing a `SKILL.md` with YAML frontmatter `name` and `description`. This folder is the canonical cross-agent skill source.

Selected skills were adapted from [kbongcawel-viatrm/ai-stack](https://github.com/kbongcawel-viatrm/ai-stack). See `SOURCES.md` for provenance.

Before pushing application changes, run `workspace-validate`; it performs local syntax, tests, type-check, build, and Wrangler dry-run checks without deploying.
